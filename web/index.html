建议先在手机/系统蓝牙里配对 HC-05
浏览器端只负责 BLE 数据通道，页面需要运行在支持 Web Bluetooth 的 Chromium 浏览器中，且使用 HTTPS 或 localhost。
本页已针对 HC-05 使用 FFE0/FFE1 接收数据，并以稳定模式运行：只记录关键连接事件和收到的文本片段，不再逐包打印 HEX。如果 HC-05 使用的是经典蓝牙 SPP，则浏览器无法直连，需要先做 SPP ↔ BLE 桥接。
数据协议匹配规则
页面会按 BMP: ...、DHT: ...、LUX: ... 三段解析来自设备的透传文本，更新到三个卡片中。
